# EARTH / OBSERVE — Offline Field Desk

スマートフォンを優先した、保存済み災害データのオフライン閲覧用プロジェクトです。元の `../index.html` には手を加えていません。

## できること

- 保存した地震・津波・気象・その他災害を、地球儀と時系列ログで確認
- 日本付近を正面に表示。地球儀を指やマウスで左右回転し、2本指のピンチで拡大縮小。ピン選択地点は明るい輪とラベルで強調
- 地震の保存された発生時刻と端末の現在時刻からP波・S波の参考円を毎秒再計算し、オフラインでも発生15分後に消去
- 「日本のみ」を災害種別と独立して切り替え。種別を選んだまま国内に絞り込み
- 地球儀とログの表示期間を過去1日・3日・7日から選択
- フィルター、日本国内のみ、東京時刻表示
- オンライン接続中にP2P地震情報・USGS・GDACSから更新
- 取得データを端末内に保存し、JSONファイルで書き出し／別端末へ読み込み
- アプリ本体と世界地図データをService Workerで事前保存し、インストール後は圏外でも起動

## スマホだけで使う場合（PC不要）

このアプリは更新ボタンからP2P地震情報・USGS・GDACSへ直接アクセスするため、データ取得用のPCサーバーは不要です。スマホで単独利用するには、最初にアプリ本体をHTTPSの静的ホスティング先へ一度公開し、そのURLをスマホで開いてホーム画面に追加してください。

配布用の `offline-mobile-publish.zip` はプロジェクトの親フォルダーにあります。スマホからHTTPS対応ホスティング先へアップロードし、ZIP内のファイルをサイトのルートに展開して公開します。公開URLをスマホで開いて初回ロードを済ませれば、以後はPCを起動せず、スマホの「オンラインで更新」で取得し、端末に保存できます。圏外では保存済みデータを見られますが、新しい情報の取得にはインターネット接続が必要です。

静的ホスティング先のアカウント作成・公開操作は、このプロジェクトだけでは代行できません。公開後のアプリはサーバー側処理を使わず、スマホのブラウザーからデータ配信元へ直接アクセスします。配信元やネットワークの制限で取得できない場合は、その配信元のデータは更新されません。

### PCでローカル確認

この `offline-mobile` フォルダーで次を実行し、PCでは `http://localhost:8000/` を開きます。

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

初回にアプリを開くと、HTML・スクリプト・世界地図データが端末へ保存されます。その後はネットワークを切っても、同じブラウザーから起動できます。ブラウザーのアプリインストール機能を使うと、単独のアプリ画面として起動できます。

### スマートフォン

PCとスマートフォンを同じWi-Fiにつなぎます。PCで `ipconfig` を実行して「IPv4 アドレス」（例: `192.168.1.85`）を確認し、スマートフォンでは `http://PCのIPv4アドレス:8000/` を開きます。`localhost` はスマートフォン自身を指すため、PCのIPアドレスを使ってください。接続できない場合は、Windows ファイアウォールでPythonのプライベートネットワーク通信を許可します。

この方法は同じWi-Fi内で画面を確認するためのものです。スマートフォンにオフライン対応アプリとしてインストールするには、最初の一度HTTPSで配信したこのフォルダーをブラウザーで開き、アプリと地図データの読み込み後にホーム画面へ追加してください。インストール前にPCで取得したJSONをスマートフォンへ送り、「データを読み込む」から取り込むこともできます。

HTMLファイルだけをスマートフォンのファイルアプリで直接開く方法は、ブラウザーによって機能制限があります。オフライン起動と地図データの保存には、HTTPSまたはPCの `localhost` 上で一度開く方法を使ってください。

## 更新と持ち運び

「オンラインで更新」を押すと現在取得できる情報を取得して端末内に保存します。「データを書き出す」でJSONを保存し、別の端末で「データを読み込む」から選ぶと、同じイベントをオフラインで見られます。保存された情報の更新時刻は画面に表示されます。

オフライン中は新しい地震や災害を受信できません。地震・津波の即時警報や避難判断には公的機関の情報を使ってください。

## データファイル

- `index.html`, `styles.css`, `app.js`: モバイル向け画面
- `sw.js`, `manifest.webmanifest`: オフラインキャッシュとホーム画面インストール
- `world-countries-50m.geojson`: 地球儀に表示する同梱の世界地図
- `icon.svg`: アプリロゴ／アイコン
